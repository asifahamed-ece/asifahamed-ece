# Vendored assets

Static artwork used by the profile README, committed here so the README does
not depend on any outside CDN. Regenerate/refresh with:

```bash
python3 tools/vendor_assets.py --skip-emojis
```

## Why the emoji PNGs are *not* vendored

The README still pulls 19 animated emoji from
[Tarikul-Islam-Anik/Animated-Fluent-Emojis](https://github.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis).
They are deliberately left on the upstream CDN because that repository ships a
**Personal Use Only** licence:

> This repository is for strictly personal use only.
> All rights reserved by Microsoft, which retains the authority to restrict its
> use in personal projects.

Committing that artwork into a public repository is a redistribution the
licence does not clearly grant, so `tools/vendor_assets.py` refuses to fetch it
unless `--skip-emojis` is omitted.

All 19 URLs were verified to return HTTP 200, so nothing is currently broken by
leaving them upstream. If that repository ever disappears, the options are:

1. Replace them with OpenMoji or Twemoji (both CC-BY / CC0), or
2. Drop the decorative emoji and keep the headings, or
3. Generate equivalents locally and commit those.

Removing the dependency without redistributing restricted artwork is the point
of this directory, so option 1 or 2 is preferred when it becomes necessary.
